## 🚀 快速使用指引

### 1. 下载安装
前往本仓库右侧的 [**Releases**](https://github.com/) 页面，下载最新的 `雀魂智囊助手_商业版`。

### 2. 解压运行
1. 解压压缩包到任意英文或中文目录下。
2. 鼠标双击运行 `雀魂智囊助手_商业版.exe`（首次运行会自动申请管理员权限以拉起本地网络分流）。

### 3. 卡密激活
1. 首次打开软件后，在弹出的授权窗口中粘贴您获得的**正版卡密**。
2. 点击【立即激活绑定】，即可永久/在有效期内畅享全部 AI 决策与代打功能。

### 4. 启动对局
1. 在主控制台点击 **【一键启动 AI 辅助】**。
2. 打开 Steam 客户端启动《雀魂麻将》，进入段位战或友人房。
3. 战术 HUD 悬浮窗将在对局发牌后自动吸附并给出最优决策！

## ⚠️ 常见问题排查 (FAQ)

- **Q: 为什么提示需要管理员权限？**  
  A: 软件底层使用高速网络虚拟网卡（TUN 协议）精确捕获游戏对局数据，需要 Windows 管理员权限创建本地虚拟端口。
- **Q: 杀毒软件误报拦截怎么办？**  
  A: 软件经过代码混淆与深度学习权重加密，部分安全软件可能会误报。请将软件目录加入信任区或 Windows Defender 白名单即可正常运行。
- **Q: 换电脑使用卡密怎么办？**  
  A: 卡密采用一机一码硬件绑定，如需解绑更换设备，请联系管理员或售后客服处理。
